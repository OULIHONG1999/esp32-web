# F3: 第三方/社区 Web 烧录方案与替代通道

## Findings

### [1] ESP Web Tools（ESPHome/Open Home Foundation 出品，非乐鑫官方）是当前最成熟的"浏览器直连烧录"第三方方案，通过 Web Serial 直接向浏览器内的 ESP 设备写固件
- quote: "User friendly tools to manage ESP8266 and ESP32 devices in the browser: Install & update firmware, Connect device to the Wi-Fi network… ESP Web Tools works by combining Web Serial, Improv Wi-Fi (optional), and a manifest which describes the firmware."
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high

### [2] ESP Web Tools 的浏览器直连烧录有硬性环境约束：需 HTTPS 页面、Chrome/Edge/Firefox（Web Serial），iOS 不可用，Android "可能但尚未实现"，manifest 需声明芯片族（ESP8266/ESP32/C2/C3/C5/C6/C61/H2/P4/S2/S3）自动选型
- quote: "Web Serial is available in Mozilla Firefox, Google Chrome and Microsoft Edge browsers (but not on your iOS device). Android support should be possible but has not been implemented yet." / "Note: ESP Web Tools requires that your website is served over `https://` to work. This is a Web Serial security requirement."
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high

### [3] 用 ESP Web Tools 烧 ESP-IDF v4+ 固件前必须先用 esptool merge_bin 合成单镜像，因为它无法像命令行 esptool 那样在线修补 flash frequency/size/mode——这是社区 Web 烧录与 esptool.py 的关键能力差距
- quote: "ESP Web Tools is not able to do this on the fly, so you will need to use `esptool` to create the single binary file and use that with ESP Web Tools."
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high

### [4] 大量量产级在线烧录站实际构建在 ESP Web Tools 之上（WLED、Tasmota、ESPEasy、ESPHome 等官方安装页），说明它已是第三方"网页端烧录"事实标准
- quote: "Products using ESP Web Tools: WLED (install.wled.me), Tasmota (arendst.github.io/Tasmota-firmware/), ESPEasy, ESPHome (web.esphome.io), Squeezelite-ESP32, Clockwise, Firefly Luciferin, OpenEpaperLink, OpenSpool, TRMNL…"
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high

### [9] Arduino Web Editor / Arduino Cloud 的上传并非浏览器直连：它依赖本地常驻 Go 程序 "Arduino Cloud Agent"（arduino/arduino-create-agent，AGPL-3.0，465 star，2026-09-23 仍在提交），浏览器经 WebSocket/REST 调 agent，由 agent 通过串口烧板
- quote: "The Arduino Cloud Agent is a single binary that will sit on the traybar and work in the background. It allows you to use the Arduino Cloud to seamlessly upload code to any USB connected Arduino board (or Yún in LAN) directly from the browser." + 架构图 "Browser --Web socket/REST API--> Arduino Cloud Agent --serial--> Arduino Board (flashes)"
- url: https://raw.githubusercontent.com/arduino/arduino-create-agent/main/README.md
- source_type: primary
- published: unknown (repo pushed 2026-09-23)
- confidence: high

- quote: "Native extensions… contain built-in PlatformIO Core (CLI) and PlatformIO Home… Desktop IDEs: CLion, CodeBlocks, Eclipse… Cloud IDEs: Cloud9, Codeanywhere, Eclipse Che." / "It also was installed by over 3,000,000 unique developers around the world."
- url: https://docs.platformio.org/en/latest/integration/ide/index.html
- source_type: primary
- published: unknown (docs v6.2.1b2)

### [11] 作为"网页端更新"替代品的设备侧 OTA：ESP-IDF 的 OTA 是设备在正常运行时经 Wi-Fi/蓝牙/以太网自更新，与浏览器串口烧录完全不同的通道；安全模式要求 ota_0/ota_1 双分区 + otadata，应用回滚默认开启（CONFIG_BOOTLOADER_APP_ROLLBACK）
- quote: "The OTA update mechanism allows a device to update itself based on data received while the normal firmware is running (for example, over Wi-Fi, Bluetooth or Ethernet)." / "Application rollback is enabled by default via CONFIG_BOOTLOADER_APP_ROLLBACK."
- url: https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/system/ota.html
- source_type: primary
- published: unknown (ESP-IDF "latest", © 2016-2026)
- confidence: high

### [12] esp_https_ota 提供"经 HTTPS 拉取固件升级"的简化 API（OTA 逻辑的抽象层），支持服务器证书校验、分段下载、断点续传、签名校验与预加密固件——这是设备联网升级的标准实现，而非浏览器直写 flash
- quote: "`esp_https_ota` provides simplified APIs to perform firmware upgrades over HTTPS. It is an abstraction layer over the existing OTA APIs."
- url: https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-reference/system/esp_https_ota.html
- source_type: primary
- published: unknown (ESP-IDF "latest", © 2016-2026)
- confidence: high

### [13] ESP RainMaker 是乐鑫的端到端云端方案（Claiming + 固件 Agent + Cloud + 手机 App），其固件仓库内建完整 OTA 子系统（esp_rmaker_ota.c、esp_rmaker_mqtt_ota.c 60KB、esp_rmaker_https_ota.c、rmaker_ota_server.crt），即经 MQTT/HTTPS 由云端/App 触发的设备侧更新，不是浏览器直连烧录
- quote: "ESP RainMaker is an end-to-end solution offered by Espressif… The primary components… Claiming Service, RainMaker Agent (i.e. this repo, to develop the firmware), RainMaker Cloud (backend…), RainMaker Phone App/CLI" + 仓库文件: components/esp_rainmaker/src/ota/esp_rmaker_mqtt_ota.c (60,243 bytes), esp_rmaker_https_ota.c, include/esp_rmaker_ota.h, server_certs/rmaker_ota_server.crt
- url: https://raw.githubusercontent.com/espressif/esp-rainmaker/master/README.md
- source_type: primary
- published: unknown (master branch)
- confidence: high

## Dead ends
- DuckDuckGo（html/lite）、Brave Search、Mojeek（captcha）、web.archive.org CDX、r.jina.ai 在本环境全部被墙或不可达；Bing 中文版对所有查询返回无关的 ESP 吉他/ESP 车身稳定系统结果，未产出可用线索。
- npm 包名 "react-webserial" 不存在（404）；实际包名为 react-web-serial（经 npm registry 搜索 API 确认）。
- docs.arduino.cc 的子页面（cloud-agent、ota-getting-started 等）为 Gatsby 客户端渲染，抓取返回空/仅 CSS；改用 arduino/arduino-create-agent 仓库 README 作为一手来源。support.arduino.cc 旧文章链接 404。
- rainmaker.espressif.com 域名解析被本环境 SSRF 防护拦截；改用 esp-rainmaker GitHub 仓库树 API（src/ota/*）确认其 OTA 实现。
- npm/官网均无 "esp-web-flasher" 主流项目；无法给出该名字对应的单一权威仓库（见 findings [8]）。

## Suggested follow-ups
- Arduino Cloud OTA 是否覆盖 ESP32 板型、是否在无 Agent 情况下经 Wi-Fi 生效（docs.arduino.cc/arduino-cloud/features/ota-getting-started 与 hardware/wifi 支持列表，需换网络环境取证）。
- WebSerial 直连烧录相对 esptool.py 的成功率/限制（ESP32-S3 原生 USB CDC、esp_web_flasher 长尾项目质量、secure-boot 设备能否被网页烧录）需要实测而非文档。
- ESP Web Tools 的 Improv-Wi-Fi 配网 + 网页日志/终端是否足以覆盖"烧录后首次配置"体验，作为选型中 UX 评估项。
