# F2: Web Serial API 浏览器机制与兼容性

## Findings

### [1] Web Serial 仅在安全上下文（HTTPS，localhost 除外）可用，且受 Permissions-Policy: serial 指令控制
- quote: "Secure context: This feature is available only in secure contexts (HTTPS), in some or all supporting browsers."
- url: https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API
- source_type: primary
- published: 2026-05-26 (last modified)
- confidence: high

### [2] 端口选择必须由用户手势触发（如点击按钮调用 requestPort()），站点只能访问用户已授权过的端口（getPorts()）；connect/disconnect 事件可让页面响应设备插拔
- quote: "If the site doesn't have access to any connected ports it has to wait until it has user activation to proceed... button.addEventListener(\"click\", ...navigator.serial.requestPort(...))"
- url: https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API
- source_type: primary
- published: 2026-05-26
- confidence: high

### [3] 截至 2026-09 的浏览器支持：Chrome 89+、Edge（mirror Chrome）、Firefox 151+ 已支持，Safari 桌面与 iOS 全系不支持，Android WebView 不支持；Chrome Android 138–147 为部分实现（仅蓝牙 RFCOMM 虚拟串口），148+ 才完整支持
- quote: "\"chrome\": {\"version_added\": \"89\"}, \"firefox\": {\"version_added\": \"151\"}, \"safari\": {\"version_added\": false}, \"webview_android\": {\"version_added\": false}"
- url: https://raw.githubusercontent.com/mdn/browser-compat-data/main/api/Serial.json
- source_type: primary
- published: 2026 (BCD main)
- confidence: high

### [4] MDN 将 Web Serial 标为 "Limited availability"（非 Baseline），因为它在部分广泛使用浏览器中不可用
- quote: "This feature is not Baseline because it does not work in some of the most widely-used browsers."
- url: https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API
- source_type: primary
- published: 2026-05-26
- confidence: high

### [5] 自动进入下载模式的硬件前提：esptool 通过拉低 USB-UART 的 DTR/RTS 控制线复位芯片——EN 接 RTS、GPIO0(strap boot) 接 DTR，两线均为低有效；DTR/RTS 同时拉低不应复位（Espressif 官方板用双三极管电路实现），且 EN 对地需 1uF–10uF 电容保证可靠
- quote: "esptool resets the chip automatically by asserting DTR and RTS control lines of the USB to serial converter chip... EN → RTS, GPIO0 → DTR... adding a capacitor between the EN pin and GND (in the 1uF-10uF range) is necessary for the reset circuitry to work reliably."
- url: https://raw.githubusercontent.com/espressif/esptool/master/docs/en/advanced-topics/boot-mode-selection.rst
- source_type: primary
- published: 2026 (esptool v5 docs)
- confidence: high

### [6] esptool 官方明确列出无法自动复位的三种情况：硬件未把 DTR/RTS 接到 EN/GPIO0、接线方式不同、或串口根本没有 DTR/RTS 控制线——此时只能手动按 BOOT 键进入下载模式；网页方案同样受限于此，浏览器无法替用户按物理按键
- quote: "esptool is not able to reset your hardware automatically in the following cases: Your hardware does not have the DTR and RTS lines connected to EN and GPIO0... There are no such serial control lines at all"
- url: https://raw.githubusercontent.com/espressif/esptool/master/docs/en/advanced-topics/boot-mode-selection.rst
- source_type: primary
- published: 2026
- confidence: high

### [7] Web Serial 与 WebUSB 是不同层级的 API：Web Serial 操作系统已提供驱动的虚拟串口（USB CDC-AM / 蓝牙 SPP），WebUSB 访问的是"未被 OS 驱动 claim 的原始 USB 设备"；MDN 明确以 ESP32 作为 Web Serial 的典型设备举例
- quote: "These may be connected via a serial port, or be USB or Bluetooth devices that emulate a serial port... distinct from devices accessed via the WebUSB API — which provides raw access to USB devices that have not been claimed by an OS driver"
- url: https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API
- source_type: primary
- published: 2026-05-26
- confidence: high

### [8] Web Serial 在 Dedicated Web Worker 中也可用，站点可用 connect/disconnect 事件监听设备插拔
- quote: "This feature is available in Dedicated Web Workers."
- url: https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API
- source_type: primary
- published: 2026-05-26
- confidence: high

### [9] requestPort() 必须在 transient activation（用户手势）中调用；站点首次访问时不拥有任何串口权限，只能经用户在端口选择弹窗中选中后获得授权
- quote: "This method must be called via transient activation. The user has to interact with the page or a UI element in order for this feature to work."
- url: https://developer.mozilla.org/en-US/docs/Web/API/Serial/requestPort
- source_type: primary
- published: 2026-05-19 (page last modified)
- confidence: high

### [10] Permissions-Policy `serial` 指令默认 allowlist 为 `self`（跨源 iframe 默认被拒）；被策略阻止时 requestPort()/getPorts() 均以 SecurityError 拒绝
- quote: "The default allowlist for `serial` is `self`." / "Serial.requestPort() and Serial.getPorts() calls will return a Promise that rejects with a DOMException of type `SecurityError`."
- url: https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Permissions-Policy/serial
- source_type: primary
- published: 2025-07-04 (page last modified)
- confidence: high

### [11] 串口独占的异常语义：对已打开的 SerialPort 再次 open() 抛 InvalidStateError，打开失败抛 NetworkError——一个端口同一时刻只能被打开一次（多标签页/串口助手冲突的表现形式）
- quote: "InvalidStateError — If open() is called when the port is already open. NetworkError — If the attempt to open the port failed."
- url: https://developer.mozilla.org/en-US/docs/Web/API/SerialPort/open
- source_type: primary
- published: 2026-05-19 (page last modified)
- confidence: high
