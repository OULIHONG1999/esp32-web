# F1: 乐鑫官方 Web 烧录方案

## Findings

### [1] esptool-js 最新正式版为 v0.7.0，发布于 2026-09-21，且 2026 年内保持高频迭代（0.6.0 → 2026-03-26，0.6.1 → 2026-08-06）
- quote: "## [v0.7.0](https://github.com/espressif/esptool-js/releases/tag/v0.7.0) - 2026-09-21"
- url: https://raw.githubusercontent.com/espressif/esptool-js/main/CHANGELOG.md
- source_type: primary
- published: 2026-09-21
- confidence: high

### [2] esptool-js 的架构是纯 Web Serial API 客户端库（TypeScript/rollup 构建，npm 包名 esptool-js，Apache-2.0），官方声明仅支持 Chrome/Edge 89+ 及 Android Chrome 61+（经 web-serial-polyfill）
- quote: "`esptool-js` is based on [Web Serial API](https://wicg.github.io/serial/) and works in Google Chrome and Microsoft Edge version 89 or later browsers and Google Chrome on Android version 61 or later via the web-serial-polyfill compatibility layer."
- url: https://github.com/espressif/esptool-js
- source_type: primary
- published: unknown
- confidence: high

### [3] esptool-js 明确的能力边界：不实现 ELF→bin 二进制生成，也不包含 espefuse/espsecure 的对应功能（相比 Python esptool）
- quote: "Unlike the Python-based esptool, `esptool-js` doesn't implement generation of binary images out of ELF files, and doesn't include companion tools similar to espefuse.py and espsecure.py."
- url: https://github.com/espressif/esptool-js
- source_type: primary
- published: unknown
- confidence: high

### [4] esptool-js 的芯片覆盖随 changelog 持续扩展：ESP32-C2（v0.4.0, 2024-01）、ESP32-P4（v0.4.4, 2024-07）、ESP32-C5（v0.4.6, 2024-10）、ESP32-C61（v0.4.7, 2024-10）、ESP32-H2（v0.3.0, 2023-06），v0.7.0 又加入 ESP32-C5 rev1.2 支持并修复 P4/C6/C61/H2 的 flash 读写问题
- quote: "Add ESP32-P4 Stub and flash support"
- url: https://raw.githubusercontent.com/espressif/esptool-js/main/CHANGELOG.md
- source_type: primary
- published: 2024-07-18
- confidence: high

### [5] esptool-js 官方在线 demo（espressif.github.io/esptool-js）明确标注不支持 Safari，并新增了 WebUSB (CH340) 实验通道，因为桌面 OS 内核 usbserial 驱动常占用 CH340 导致 Web Serial claimInterface 失败，Android/Chrome OTG 才是可靠的 WebUSB 场景
- quote: "This tool is not supported on Safari browser!"
- url: https://espressif.github.io/esptool-js/
- source_type: primary
- published: unknown
- confidence: high

### [6] 乐鑫官方 esptool 文档（v5, docs.espressif.com）在 "Alternatives" 章节将 esptool.js 列为浏览器/Node.js 可用的官方替代方案，同时声明 Python esptool 功能最全、最新芯片与特性总是最先在这里获得支持
- quote: "esptool.js is a JavaScript port of esptool that can be used in a web browser or in a Node.js environment."
- url: https://docs.espressif.com/projects/esptool/en/latest/
- source_type: primary
- published: unknown
- confidence: high
- quote2: "Among these, esptool is the most feature-rich, and support for the newest chips and features usually appears here first."

### [7] esp-web-tools 的 npm 最新版为 10.4.0（约 2026-07-15 发布），内部依赖 esptool-js ^0.6.0 与 lit ^3.2.1、improv-wifi-serial-sdk 2.8.0，即它是 esptool-js 之上的封装层
- quote: "\"dependencies\":{\"lit\":\"^3.2.1\",\"tslib\":\"^2.8.1\",\"esptool-js\":\"^0.6.0\""
- url: https://registry.npmjs.org/esp-web-tools/latest
- source_type: primary
- published: 2026-07-15
- confidence: high

### [8] esp-web-tools 并非乐鑫出品，而是 ESPHome / Open Home Foundation 项目、由 Nabu Casa 资助（代码仓库已位于 esphome 组织），只是长期被 Espressif 生态产品广泛采用
- quote: "ESP Web Tools is a project by [ESPHome](https://esphome.io), [Open Home Foundation](https://www.openhomefoundation.org). Development is funded by [Nabu Casa](https://www.nabucasa.com)."
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high

### [9] esp-web-tools 的 manifest 是 JSON 格式：`builds[]` 每项含 `chipFamily` 与 `parts[]`（path + flash offset），工具自动检测所连芯片并选对应 build，官方列出的支持芯片家族为 ESP8266、ESP32、ESP32-C2/C3/C5/C6/C61、ESP32-H2、ESP32-P4、ESP32-S2、ESP32-S3；README 另注明可为 USB-CDC/UART 双栈芯片用 `serialType: "cdc"|"uart"` 提供不同变体
- quote: "Current supported chip families are `ESP8266`, `ESP32`, `ESP32-C2`, `ESP32-C3`, `ESP32-C5`, `ESP32-C6`, `ESP32-C61`, `ESP32-H2`, `ESP32-P4`, `ESP32-S2` and `ESP32-S3`."
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high
- quote2: "The optional `serialType` field (`\"cdc\"` or `\"uart\"`) lets you ship separate firmware variants for chips that support both native USB CDC (built-in USB) and external USB-to-UART bridges."
- url2: https://raw.githubusercontent.com/esphome/esp-web-tools/main/README.md

### [10] esp-web-tools 的部署约束：仅 Web Serial（Firefox/Chrome/Edge 桌面版可用，iOS 不支持，Android 支持"尚未实现"），站点必须 HTTPS（Web Serial 安全要求），跨域托管 manifest/固件需配置 CORS 头
- quote: "Web Serial is available in Mozilla Firefox, Google Chrome and Microsoft Edge browsers (but not on your iOS device). Android support should be possible but has not been implemented yet."
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high
- quote2: "ESP Web Tools requires that your website is served over `https://` to work. This is a Web Serial security requirement."

### [11] esp-web-tools 的能力超出纯烧录：烧录后可走 Improv Wi-Fi 串口标准配网、访问设备 Web 界面、查看日志/发送终端命令、一键接入 Home Assistant；且 ESP-IDF v4+ 的四段式固件必须先用 esptool merge_bin 合并，因为它无法像命令行 esptool 那样在烧录时动态修补 flash 频率/大小/模式
- quote: "ESP Web Tools is not able to do this on the fly, so you will need to use `esptool` to create the single binary file and use that with ESP Web Tools."
- url: https://esphome.github.io/esp-web-tools/
- source_type: primary
- published: unknown
- confidence: high

### [12] ESP Launchpad（espressif.github.io/esp-launchpad，仓库 espressif/esp-launchpad，页脚 "Copyright © 2026 Espressif Systems"）是乐鑫自家的 Web Serial 网页烧录工具，提供 Quick Start（内置 RainMaker/Matter 固件，Plug→Connect→Choose→Flash 四步）与 DIY（本地多文件按地址烧录）两种模式，对外发布固件用 TOML 配置（`esp_toml_version = 1.0`，样例 chipsets 为 ESP32/ESP32-S2/ESP32-C3/ESP32-S3，可配 developKits 与 console_baudrate），通过 `?flashConfigURL=...` 引用、`&crossDomain=true` 走内置 CORS 代理，烧录波特率最高 921600，仅 HTTPS/localhost 可用
- quote: "ESP Launchpad is a web based tool, available for flashing firmware application to the ESP32 device connected via USB serial port."
- url: https://raw.githubusercontent.com/espressif/esp-launchpad/main/README.md
- source_type: primary
- published: unknown
- confidence: high
- quote2: "chipsets = [\"ESP32\", \"ESP32-S2\", \"ESP32-C3\", \"ESP32-S3\"]"
- url2: https://raw.githubusercontent.com/espressif/esp-launchpad/main/config/config.toml
