AI 速读 · 本页是什么

机器可读描述符 /drive.json

本页是云盘：宿主机/智能体把任意文件上传到云端，设备经 fetch 命令下载安装到 /fs 或 /sdcard，智能体/人经 HTTP 直接下载查看。数据全部来自服务器实时接口（无本地假数据），每 5 秒轮询。

接口（契约详见 /docs/cloud-drive.md §4）

  • POST /api/drive/files上传 · 需 Bearer（multipart file+note 或 raw body + X-Filename）
  • GET /api/drive/files列表 · 公开只读
  • GET /api/drive/files/{fileId}下载原始字节 · 公开只读（?meta=1 返回元数据）
  • DELETE /api/drive/files/{fileId}删除 · 需 Bearer · 幂等

命名与约定

fileId
服务端生成 f_xxxxxxxx，与用户文件名解耦，落盘 server-data/drive/<fileId>
下载 URL
/api/drive/files/{fileId}——直接填进 fetch 命令的 url
单文件上限
8 MB；总配额 1 GB（超额 413）
读 / 写
读（列表/下载）开放——设备端无凭据下载；写（上传/删除）需 Bearer token

推荐抓取顺序：/drive.json → /docs/cloud-drive.md → 本页。 与 fetch 通道衔接见 契约 §7。
