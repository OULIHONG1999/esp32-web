最小调用示例

POST /api/subset Content-Type: application/json 
{
  "font": "misans-regular",
  "chars": "天青色等烟雨"
}

返回 font/ttf。响应头：X-Cache-Hit / X-Subset-Bytes / X-Subset-Ms。 无 px 参数（字号归设备端）。
